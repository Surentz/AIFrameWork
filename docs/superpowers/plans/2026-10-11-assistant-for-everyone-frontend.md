# The Assistant for Everyone (frontend) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every signed-in user opens the assistant from an icon in the header and gets a
Claude-desktop-style page: a sidebar of their conversations (grouped by age, renameable,
deletable) and a centred chat column with Markdown answers, tool chips and a pinned composer.

**Architecture:** Builds on the backend plan's endpoints (merged first). `/assistant` and
`/assistant/:conversationId` render `AssistantPage`: `ConversationSidebar` (TanStack Query over
`GET /api/assistant/conversations`) beside a `Chat` (the existing reducer and stream, seeded from
`GET …/{id}` for a saved conversation). A small `useChatSession` hook decides when the chat is a
fresh instance and when a new chat keeps its instance as its URL gains the saved id. Answers render
through `react-markdown` + `remark-gfm` with raw HTML never interpreted.

**Tech Stack:** React 19, TypeScript 6 (strict, `exactOptionalPropertyTypes`,
`noUncheckedIndexedAccess`), TanStack Query, React Router, `react-markdown` 10, `remark-gfm` 4,
Vitest + Testing Library + MSW 3, Playwright; one change in `tests/PartnerSimulator` (C#).

**Spec:** `docs/superpowers/specs/2026-10-11-assistant-for-everyone-design.md` §4, §5 (frontend
rows), §6 PR 2. Mockup (style B): `.superpowers/brainstorm/*/content/assistant-page.html` (local,
not committed). Depends on `docs/superpowers/plans/2026-10-11-assistant-for-everyone-backend.md`
being merged: its regenerated `frontend/src/api/schema.d.ts` carries the types below.

## Global Constraints

- `npm run lint` is `eslint . --max-warnings 0`. No `any`, no `!`, explicit return types on
  exported functions, components return `React.JSX.Element` (or `| null` where they may render
  nothing).
- Models are aliases over `src/api/schema.d.ts` in `features/assistant/types.ts`.
- Server state is TanStack Query; the streamed conversation is the existing reducer. No
  `useEffect` for fetching.
- Every request goes through `src/api/client.ts` (`request`, `requestVoid`, `requestStream`).
- Tests: MSW with `onUnhandledFrame: 'error'`; never `vi.mock` the API client; query by role and
  accessible name; `findBy*` never fixed timeouts; one behaviour per `it`.
- Copy, exactly: the empty state heading **"How can I help you today?"**; the note **"Answers are
  generated by Claude from your data. Check before acting."**; the 429 message **"You've asked a
  lot in the last hour — try again later."**; sidebar groups **"Today"**, **"Previous 7 days"**,
  **"Previous 30 days"**; the button **"New chat"**; the header icon's accessible name
  **"Assistant"**.
- Limits: 2,000 characters per question, the counter shown only past **1,800**; titles at most
  **60** characters.
- Model output is untrusted: no `rehype-raw`, no `dangerouslySetInnerHTML`; links open with
  `target="_blank" rel="noopener noreferrer"`.
- Styling: plain CSS with the tokens in `src/styles/tokens.css`; no UI library.
- Commits: `feat(assistant): …`, ending `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  PR title `feat(assistant): a Claude-desktop-style assistant page for everyone`.

**One deliberate departure from the spec's wording:** the spec says the send button "turns into" a
stop button. #117 found that swapping one button for another in place lets a double-click's second
click stop the question it just sent. So **Send stays where it is, disabled while streaming, and a
Stop button appears beside it.** Say so in the PR.

## Review Focus

1. **A new chat's first answer gives it an id** and the URL becomes `/assistant/<id>`. Expected: the
   chat is not remounted (the answer stays on screen, the stream is not cut) and the next question
   sends that id. Test in Task 5.
2. **Leaving a chat by any route** — another conversation in the sidebar, New chat, the header icon
   while already on `/assistant`. Expected: a fresh chat each time, never the previous one's
   messages. Test in Task 5.
3. **The model writes HTML or a `javascript:` link.** Expected: no element is created from it, and
   no script URL is clickable. Test in Task 2.
4. **The open conversation is deleted from the sidebar.** Expected: the page goes to a new chat,
   the list no longer shows it. Test in Task 3.
5. **A failed question, then New chat** (an expired conversation). Expected: the failed question is
   still in the composer, so asking again is one click. Test in Task 4 (restore) and Task 5 (draft
   survives New chat).

```ts
const conversationPath = (id: string): string =>
  `/api/assistant/conversations/${encodeURIComponent(id)}`;

/** The caller's conversations, most recently active first (at most 30 days of them). */
export function listConversations(): Promise<readonly ConversationSummary[]> {
  return request<readonly ConversationSummary[]>('/api/assistant/conversations');
}

export function getConversation(id: string): Promise<SavedConversation> {
  return request<SavedConversation>(conversationPath(id));
}

export function renameConversation(id: string, title: string): Promise<void> {
  return requestVoid(conversationPath(id), { method: 'PATCH', body: JSON.stringify({ title }) });
}

export function deleteConversation(id: string): Promise<void> {
  return requestVoid(conversationPath(id), { method: 'DELETE' });
}
```

```ts
export const assistantKeys = {
  all: ['assistant'] as const,
  status: () => [...assistantKeys.all, 'status'] as const,
  conversations: () => [...assistantKeys.all, 'conversations'] as const,
  conversation: (id: string) => [...assistantKeys.conversations(), id] as const,
};

/** The sidebar. Every saved answer, rename and delete invalidates it. */
export function useConversations(): UseQueryResult<readonly ConversationSummary[], ApiError> {
  return useQuery<readonly ConversationSummary[], ApiError>({
    queryKey: assistantKeys.conversations(),
    queryFn: listConversations,
  });
}

/**
 * One saved conversation, read once when it is opened: the chat it seeds owns the messages from
 * then on. No cache across visits (gcTime 0) and no background refetch, so reopening always shows
 * what was saved and a refetch can never replace a chat that is streaming.
 */
export function useSavedConversation(id: string): UseQueryResult<SavedConversation, ApiError> {
  return useQuery<SavedConversation, ApiError>({
    queryKey: assistantKeys.conversation(id),
    queryFn: () => getConversation(id),
    gcTime: 0,
    refetchOnWindowFocus: false,
    refetchOnReconnect: false,
  });
}

interface RenameInput {
  readonly id: string;
  readonly title: string;
}

export function useRenameConversation(): UseMutationResult<void, ApiError, RenameInput> {
  const queryClient = useQueryClient();
  return useMutation<void, ApiError, RenameInput>({
    mutationFn: ({ id, title }) => renameConversation(id, title),
    onSuccess: () =>
      queryClient.invalidateQueries({ queryKey: assistantKeys.conversations(), exact: true }),
  });
}

export function useDeleteConversation(): UseMutationResult<void, ApiError, string> {
  const queryClient = useQueryClient();
  return useMutation<void, ApiError, string>({
    mutationFn: deleteConversation,
    onSuccess: () =>
      queryClient.invalidateQueries({ queryKey: assistantKeys.conversations(), exact: true }),
  });
}
```

```tsx
 * Links leave the app in a new tab and get no handle on it. react-markdown's default URL transform
 * already empties javascript: and other unsafe URLs before this sees them.

  a: ({ href, children }) => (

      {children}
    </a>
  ),
};

  readonly text: string;

  return (
    <div className="assistant-markdown">

}
```

`frontend/src/features/assistant/history.ts`:

```ts
import type { ConversationSummary } from './types';

export interface ConversationGroup {
  readonly label: 'Today' | 'Previous 7 days' | 'Previous 30 days';
  readonly items: readonly ConversationSummary[];
}

const DayMs = 24 * 60 * 60 * 1000;

/**
 * The sidebar's groups, by last activity in the viewer's own time zone. The server keeps 30 days,
 * so "Previous 30 days" is everything older than a week. Empty groups are left out; the input's
 * newest-first order is kept within each group.
 */
export function groupByAge(
  conversations: readonly ConversationSummary[],
  now: Date,
): ConversationGroup[] {
  const startOfToday = new Date(now.getFullYear(), now.getMonth(), now.getDate()).getTime();
  const today: ConversationSummary[] = [];
  const week: ConversationSummary[] = [];
  const older: ConversationSummary[] = [];

  for (const conversation of conversations) {
    const at = Date.parse(conversation.lastActiveAt);
    if (at >= startOfToday) {
      today.push(conversation);
    } else if (at >= startOfToday - 7 * DayMs) {
      week.push(conversation);
    } else {
      older.push(conversation);
    }
  }

  const groups: ConversationGroup[] = [
    { label: 'Today', items: today },
    { label: 'Previous 7 days', items: week },
    { label: 'Previous 30 days', items: older },
  ];
  return groups.filter((group) => group.items.length > 0);
}
```

```tsx
interface ConversationRowProps {
  readonly conversation: ConversationSummary;
  readonly active: boolean;
}

type RowMode = 'view' | 'menu' | 'rename' | 'confirm';

function ConversationRow({ conversation, active }: ConversationRowProps): React.JSX.Element {
  const [mode, setMode] = useState<RowMode>('view');
  const rename = useRenameConversation();
  const remove = useDeleteConversation();
  const navigate = useNavigate();

  function submitRename(event: SubmitEvent<HTMLFormElement>): void {
    event.preventDefault();
    const title = new FormData(event.currentTarget).get('title');
    const trimmed = typeof title === 'string' ? title.trim() : '';
    if (trimmed === '' || trimmed === conversation.title) {
      setMode('view');
      return;
    }

    rename.mutate({ id: conversation.id, title: trimmed }, { onSuccess: () => setMode('view') });
  }

  function cancelOnEscape(event: KeyboardEvent<HTMLInputElement>): void {
    if (event.key === 'Escape') {
      setMode('view');
    }
  }

  function confirmDelete(): void {
    remove.mutate(conversation.id, {
      onSuccess: () => {
        if (active) {
          void navigate('/assistant');
        }
      },
    });
  }

  return (
    <li className={active ? 'assistant-row assistant-row--active' : 'assistant-row'}>
      {mode === 'rename' ? (
        <form onSubmit={submitRename}>
          <input
            name="title"
            className="assistant-row__input"
            aria-label="Conversation title"
            defaultValue={conversation.title}
            maxLength={MaxTitleLength}
            // The user just chose Rename: the input is the one thing they act on next.
            // eslint-disable-next-line jsx-a11y/no-autofocus
            autoFocus
            onKeyDown={cancelOnEscape}
          />
        </form>
      ) : (
        <div className="assistant-row__line">
          <Link
            className="assistant-row__link"
            to={`/assistant/${conversation.id}`}
            aria-current={active ? 'page' : undefined}
          >
            {conversation.title}
          </Link>
          <button
            type="button"
            className="assistant-row__more"
            aria-label={`Options for ${conversation.title}`}
            aria-expanded={mode !== 'view'}
            onClick={() => setMode(mode === 'view' ? 'menu' : 'view')}
          >
            ⋯
          </button>
        </div>
      )}

      {mode === 'menu' && (
        <div className="assistant-row__menu">
          <button type="button" onClick={() => setMode('rename')}>
            Rename
          </button>
          <button type="button" onClick={() => setMode('confirm')}>
            Delete
          </button>
        </div>
      )}

      {mode === 'confirm' && (
        <div className="assistant-row__menu" role="group" aria-label="Confirm delete">
          <span>Delete this conversation?</span>
          <button type="button" className="assistant-row__danger" onClick={confirmDelete}>
            Delete conversation
          </button>
          <button type="button" onClick={() => setMode('view')}>
            Cancel
          </button>
        </div>
      )}

      {rename.error && <ErrorPanel error={rename.error} />}
      {remove.error && <ErrorPanel error={remove.error} />}
    </li>
  );
}
```

```tsx
import type { KeyboardEvent, SubmitEvent } from 'react';

export const MaxQuestionLength = 2000;

/** The counter appears only when it matters. */
const CountFrom = 1800;

interface ComposerProps {
  readonly value: string;
  readonly onChange: (value: string) => void;
  readonly onSend: () => void;
  readonly onStop: () => void;
  readonly streaming: boolean;
  readonly placeholder: string;
}

/**
 * The input pinned under the chat. Enter sends; Shift+Enter (or Enter while an IME is composing)
 * is a newline. Send stays in place, disabled while an answer streams, and Stop appears beside it:
 * a button that changed into Stop under the pointer let a double-click stop what it just sent.
 */
export function Composer({
  value,
  onChange,
  onSend,
  onStop,
  streaming,
  placeholder,
}: ComposerProps): React.JSX.Element {
  const blank = value.trim() === '';

  function submit(event: SubmitEvent<HTMLFormElement>): void {
    event.preventDefault();
    if (!blank && !streaming) {
      onSend();
    }
  }

  function sendOnEnter(event: KeyboardEvent<HTMLTextAreaElement>): void {
    if (event.key === 'Enter' && !event.shiftKey && !event.nativeEvent.isComposing) {
      event.preventDefault();
      event.currentTarget.form?.requestSubmit();
    }
  }

  return (
    <div className="assistant-composer-wrap">
      <form className="assistant-composer" onSubmit={submit}>
        <label htmlFor="assistant-question" className="visually-hidden">
          Your question
        </label>
        <textarea
          id="assistant-question"
          className="assistant-composer__input"
          value={value}
          maxLength={MaxQuestionLength}
          rows={1}
          placeholder={placeholder}
          disabled={streaming}
          onChange={(event) => {
            onChange(event.target.value);
          }}
          onKeyDown={sendOnEnter}
        />
        {streaming && (
          <button type="button" className="assistant-composer__stop" aria-label="Stop" onClick={onStop}>
            <svg viewBox="0 0 24 24" width="14" height="14" aria-hidden="true">
              <rect x="6" y="6" width="12" height="12" rx="2" fill="currentColor" />
            </svg>
          </button>
        )}
        <button type="submit" className="assistant-composer__send" aria-label="Send" disabled={blank || streaming}>
          <svg viewBox="0 0 24 24" width="16" height="16" fill="none" stroke="currentColor"
            strokeWidth="2.2" strokeLinecap="round" strokeLinejoin="round" aria-hidden="true">
            <path d="M12 19V5M5 12l7-7 7 7" />
          </svg>
        </button>
      </form>
      {value.length > CountFrom && (
        <p className="assistant-composer__count">
          {value.length} / {MaxQuestionLength}
        </p>
      )}
      <p className="assistant-note">Answers are generated by Claude from your data. Check before acting.</p>
    </div>
  );
}
```

```tsx
interface ChatProps {
  /** A saved conversation to continue (fromSaved), or undefined for a new chat. */
  readonly initial?: ConversationState | undefined;
  readonly onSaved: (conversationId: string) => void;
  readonly operator: boolean;

/** One conversation: the messages, centred, and the composer pinned under them. */
export function Chat({ initial, onSaved, operator, draft, onDraftChange }: ChatProps): React.JSX.Element {
  const conversation = useAssistantConversation({ initial, onSaved });
  const suggestions = [
    ...memberSuggestions,
    operator ? 'Did any background job fail today?' : 'Show me the catalogue',
  ];

  function send(): void {
    const question = draft.trim();
    onDraftChange('');
    void conversation.ask(question).then((outcome) => {
      // Nothing was saved for a failed question, so put it back: asking again needs no retyping.
      if (outcome === 'failed') {
        onDraftChange(question);
      }
    });
  }

  return (
    <section className="assistant-chat" aria-label="Chat">
      <div className="assistant-chat__scroll">
        <div className="assistant-chat__column">
          {conversation.messages.length === 0 ? (
            <div className="assistant-empty">
              <h2>How can I help you today?</h2>
              <div className="assistant-empty__suggestions">
                {suggestions.map((suggestion) => (
                  <button key={suggestion} type="button" onClick={() => onDraftChange(suggestion)}>
                    {suggestion}
                  </button>
                ))}
              </div>
            </div>

                  message={message}
                  thinking={

                    index === conversation.messages.length - 1 &&
                    message.text === ''

                />

            </ol>
          )}

          {conversation.error && <AssistantError error={conversation.error} />}

      )}
      {message.outcome === 'Truncated' && <p className="muted">This answer was cut short.</p>}
    </li>
  );
}

  }
```

- [ ] **Step 3: Write the chat session hook**

`frontend/src/features/assistant/chatSession.ts`:

```ts
import { useCallback, useState } from 'react';

interface SessionState {
  /** A new chat that was given this id by its first answer, and is still the chat on screen. */
  readonly adopted: string | undefined;
  /** Bumped for every fresh new chat, so its key changes even when the address does not. */
  readonly generation: number;
}

export interface ChatSession {
  /** The key the chat renders under: a different key is a fresh chat instance. */
  readonly key: string;
  /** The saved conversation to load, or undefined for a new chat (adopted ones included). */
  readonly load: string | undefined;
  /** A new chat's first answer was saved as `id`: keep this instance at its new address. */
  readonly adopt: (id: string) => void;
  /** New chat: a fresh instance even when the address does not change. */
  readonly fresh: () => void;
}

/**
 * Which chat instance to show for an address. A new chat keeps its instance (and its stream) when
 * its first answer moves the address to /assistant/<id>; every other change of conversation — the
 * sidebar, New chat, the header icon — is a fresh instance.
 */
export function useChatSession(conversationId: string | undefined): ChatSession {
  const [session, setSession] = useState<SessionState>({ adopted: undefined, generation: 0 });

  // Left the adopted chat (another conversation, or /assistant from the header): forget it, and
  // make the next new chat a new instance. Adjusting state during render, the pattern React's docs
  // give for "adjusting state when a prop changes".
  if (session.adopted !== undefined && conversationId !== session.adopted) {
    setSession({ adopted: undefined, generation: session.generation + 1 });
  }

  const live = conversationId === undefined || conversationId === session.adopted;

  const adopt = useCallback((id: string) => {
    setSession((current) => ({ ...current, adopted: id }));
  }, []);

  const fresh = useCallback(() => {
    setSession((current) => ({ adopted: undefined, generation: current.generation + 1 }));
  }, []);

  return {
    key: live ? `new-${String(session.generation)}` : `saved-${conversationId}`,
    load: live ? undefined : conversationId,
    adopt,
    fresh,
  };
}
```

```tsx
import { useQueryClient } from '@tanstack/react-query';
import { useCallback, useState } from 'react';
import { useNavigate, useParams } from 'react-router-dom';
import { ErrorPanel } from '../../components/ErrorPanel';
import { useSession } from '../auth/queries';
import { Chat } from './Chat';
import { useChatSession } from './chatSession';
import { ConversationSidebar } from './ConversationSidebar';
import { fromSaved } from './conversation';
import { assistantKeys, useAssistantStatus, useSavedConversation } from './queries';
import './assistant.css';

/**
 * The assistant (ADRs 0033, 0034), for every signed-in user: the conversations on the left, the
 * open one in the middle. /assistant is a new chat; /assistant/:conversationId a saved one.
 */
export function AssistantPage(): React.JSX.Element {
  const status = useAssistantStatus();
  const { data: session } = useSession();
  const { conversationId } = useParams();
  const chat = useChatSession(conversationId);
  const navigate = useNavigate();
  const queryClient = useQueryClient();
  const [draft, setDraft] = useState('');

  const onSaved = useCallback(
    (id: string) => {
      void queryClient.invalidateQueries({ queryKey: assistantKeys.conversations(), exact: true });
      if (conversationId === undefined) {
        chat.adopt(id);
        void navigate(`/assistant/${id}`, { replace: true });
      }
    },
    [chat, conversationId, navigate, queryClient],
  );

  const newChat = useCallback(() => {
    chat.fresh();
    void navigate('/assistant');
  }, [chat, navigate]);

  if (status.isPending) {
    return <p role="status">Loading the assistant…</p>;
  }

  if (status.error) {
    return <ErrorPanel error={status.error} />;
  }

  if (!status.data.enabled) {
    return (
      <section className="assistant-off">
        <h1>Assistant</h1>
        <p>
          The assistant is switched off. An operator turns it on with <code>Assistant__Enabled</code>{' '}
          and an API key file; see <code>docs/local-development.md</code>.
        </p>
      </section>
    );
  }

  const operator = session?.role === 'Admin';

  return (
    <div className="assistant">
      <h1 className="visually-hidden">Assistant</h1>
      <ConversationSidebar activeId={conversationId} onNewChat={newChat} />
      {chat.load === undefined ? (
        <Chat key={chat.key} onSaved={onSaved} operator={operator} draft={draft} onDraftChange={setDraft} />
      ) : (
        <SavedChat key={chat.key} id={chat.load} onSaved={onSaved} operator={operator} draft={draft} onDraftChange={setDraft} />
      )}
    </div>
  );
}

interface SavedChatProps {
  readonly id: string;
  readonly onSaved: (conversationId: string) => void;
  readonly operator: boolean;
  readonly draft: string;
  readonly onDraftChange: (draft: string) => void;
}

/** Loads a saved conversation once, then hands it to the chat, which owns it from then on. */
function SavedChat({ id, ...chatProps }: SavedChatProps): React.JSX.Element {
  const saved = useSavedConversation(id);

  if (saved.isPending) {
    return (
      <p role="status" className="assistant-chat assistant-chat--placeholder">
        Loading the conversation…
      </p>
    );
  }

  if (saved.error) {
    return (
      <div className="assistant-chat assistant-chat--placeholder">
        <ErrorPanel error={saved.error} />
      </div>
    );
  }

  return <Chat initial={fromSaved(saved.data)} {...chatProps} />;
}
```

```csharp
/// <summary>
/// The e2e run's script: one tool, then an answer, so the page shows a chip and streamed text.
/// Which tool follows from what the request offers: an operator's question checks job health, a
/// member's (offered no monitoring tools) checks their orders.
/// </summary>
public static class FakeMessagesScript
{
    public const string OperatorAnswer = "No background job failed in the last 24 hours.";

    public const string MemberAnswer = "You have no open orders.";

    public static FakeReply ToolThenAnswer(JsonElement body)
    {
        var operatorTools = body.TryGetProperty("tools", out var tools)
            && tools.EnumerateArray().Any(t => string.Equals(t.GetProperty("name").GetString(), "job_health", StringComparison.Ordinal));

        var messages = body.GetProperty("messages");
        var last = messages[messages.GetArrayLength() - 1].GetProperty("content");
        var answersATool = last.ValueKind == JsonValueKind.Array
            && last.EnumerateArray().Any(block => string.Equals(block.GetProperty("type").GetString(), "tool_result", StringComparison.Ordinal));

        if (answersATool)
        {
            return operatorTools
                ? FakeReply.Text("No background job ", "failed in the last 24 hours.")
                : FakeReply.Text("You have ", "no open orders.");
        }

        return operatorTools
            ? FakeReply.ToolUse("toolu_e2e", "job_health", """{"window_hours":24}""")
            : FakeReply.ToolUse("toolu_e2e", "my_orders", """{"cursor":null}""");
    }
```

```ts
import * as assistant from '../../screens/assistant.ts';

/**
 * The assistant end to end: the real API and its tools, with the fake Messages API in Anthropic's
 * place (tests/PartnerSimulator `messages`, ADRs 0033 and 0034). The fake picks its tool from what

    const text = `Where are my orders? ${String(Date.now())}`;

    await test.step('ask from the header icon', async () => {
      await signedInPage.goto('/orders');
      await assistant.headerIcon(signedInPage).click();
      await assistant.ask(signedInPage, text);

    });
```
